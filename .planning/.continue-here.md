# BLOCKING CONSTRAINTS — Read Before Anything Else

- [ ] **CONSTRAINT: No DI container** — All services are manually instantiated in `MainViewModel` constructor. Do NOT add `Microsoft.Extensions.DependencyInjection` without refactoring the entire startup pipeline.
- [ ] **CONSTRAINT: WPF XAML namescope rules** — `ElementName` bindings fail inside DataTemplates in virtualized containers. `x:Reference` also fails across namescope boundaries. Use `RelativeSource AncestorType` for cross-template bindings.
- [ ] **CONSTRAINT: iOS on Windows is limited** — libimobiledevice Windows binaries are community-compiled. Shell, screen recording, macros, deep links, notifications, clipboard bridge are Android-only. Do NOT implement iOS versions without verifying tool support first.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| XAML Style TargetType mismatch | Applying `FilterToggleButton` (ToggleButton) to `Button` crashes with `XamlParseException` | blocking | Always verify Style TargetType matches element type before build |
| ADB command injection | Unsanitized user input in shell commands allows `$(cmd)` and `;` injection | blocking | Use base64 encoding via `echo '{b64}' \| base64 -d \| ...` pattern |
| ObservableCollection bulk remove | Per-element `RemoveAt(i)` in a loop fires N CollectionChanged events, freezing UI | blocking | Use `LogEntries.Skip(n).ToList(); Clear(); foreach Add()` batch pattern |
